# Semestra UI-theme banner pack

This version is rebuilt to match the supplied Semestra login/dashboard screen rather than the earlier university-paper direction.

Every editable SVG is 1600 × 360 pixels and uses the same visual tokens:

- canvas: `#111315`
- dashboard surface: `#1B1F23`
- rules and outlines: `#34393F`
- main text: `#E7E4DC`
- muted metadata: `#8A94A1`
- accent and action state: `#D17056`

The visual signature is the dotted registration rail, corner crosshairs, monospaced status rows, and thin outlined dashboard modules visible in the login screen.

| File | Concept |
| --- | --- |
| `workload-forecast.svg` | Weekly workload and capacity |
| `semester-map.svg` | Term dates and milestones |
| `exam-readiness.svg` | Revision status and next study block |
| `deadline-radar.svg` | Upcoming deadlines |
| `study-recovery.svg` | Catch-up plan |
| `notestra-activity.svg` | Notestra study activity |
| `weekly-review.svg` | Weekly progress review |
| `focus-windows.svg` | Protected focus periods |
| `course-balance.svg` | Course-load balance |

No linked images, scripts, or remote fonts are included.
