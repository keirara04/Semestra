# Semestra promo banner pack

Nine editable SVG banners for the wide settings-page promo slot.

Each file is 1600 × 360 pixels with a left-aligned message and a dashboard-style visual on the right. They are self-contained (no linked images, scripts, or remote fonts), so they can be dropped into a website, opened in Figma, or edited in an SVG-capable design tool.

| File | Concept |
| --- | --- |
| `workload-forecast.svg` | Weekly workload and capacity |
| `semester-map.svg` | Semester milestones and course dates |
| `exam-readiness.svg` | Revision readiness and next study block |
| `deadline-radar.svg` | Deadlines ranked by urgency |
| `study-recovery.svg` | A manageable catch-up plan |
| `notestra-activity.svg` | Notestra annotation and study activity |
| `weekly-review.svg` | Weekly progress and reflection |
| `focus-windows.svg` | Suggested deep-work time blocks |
| `course-balance.svg` | Balanced effort across courses |

Shared art direction: charcoal academic interface, warm paper typography, monospaced metadata, restrained burnt-orange calls to action, and muted course colours.
